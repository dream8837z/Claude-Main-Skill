# AI Council 쉬운 가이드 (비전공자용)

> 코딩을 몰라도 따라 할 수 있게 썼습니다. 처음 한 번만 준비하면 이후로는 **더블클릭 → 휴대폰으로 질문**이면 됩니다.

---

## 1. 이게 뭔가요?

**한 줄 요약:** 내가 구독 중인 여러 AI(Claude, Gemini, ChatGPT)에게 같은 질문을 주고, **서로의 답을 보고 토론하게 한 뒤, 가장 좋은 답 하나로 정리**해 주는 프로그램입니다.

**비유하자면 "AI 회의실"입니다.**

1. **각자 답 쓰기:** 세 명의 전문가가 같은 문제를 받고, 서로 보지 않고 각자 답을 씁니다.
2. **토론:** 다른 사람의 답을 돌려 봅니다. 이때 누가 썼는지는 가립니다. 유명한 사람 답이라고 무조건 따라가지 않게 하려는 것입니다. 틀린 곳을 지적하고, 좋은 점은 받아들여 자기 답을 고칩니다. 이 과정을 정해진 횟수만큼 반복합니다.
3. **투표:** 각자 답들의 순위를 매깁니다. 자기 답에는 표를 줄 수 없습니다.
4. **정리:** 1등 답을 바탕으로 다른 답의 좋은 부분을 합쳐 최종 답을 만듭니다. 끝까지 의견이 갈린 부분은 따로 알려 줍니다.

**왜 좋은가요?** AI 하나는 가끔 틀린 말을 자신 있게 합니다. 여러 AI가 서로 검사하면 이런 실수가 걸러질 가능성이 커집니다.

---

## 2. 꼭 알아야 할 단어 4개

| 단어 | 쉬운 뜻 |
|---|---|
| **터미널** | 글자로 컴퓨터에 명령하는 까만 창. Windows는 "PowerShell", Mac은 "터미널" 앱 |
| **CLI** | 터미널에서 쓰는 프로그램. 여기서는 Claude, Gemini, ChatGPT의 **공식 터미널용 프로그램** |
| **로그인 계정 방식** | 돈을 따로 내는 "API 키"가 아니라, **이미 쓰고 있는 구독 계정**으로 로그인해서 쓰는 방식 |
| **같은 와이파이** | PC와 휴대폰이 같은 공유기(집 와이파이)에 연결된 상태 |

---

## 3. 전체 구조 (그림으로)

```
[휴대폰 브라우저] --질문--> [내 PC: AI Council] --> Claude / Gemini / ChatGPT (내 계정)
        ^                                                    |
        └────────────────── 최종 답 ─────────────────────────┘
```

- **실제 일은 PC가 합니다.** 휴대폰은 리모컨입니다.
- 그래서 사용하는 동안 **PC가 켜져 있어야** 합니다. 휴대폰 화면은 꺼도 됩니다.

---

## 4. 처음 한 번만: 준비 (약 20~30분)

### 4-1. 필요한 것
- PC 1대 (Windows 또는 Mac)
- 아래 구독 중 **2개 이상** (1개만 있으면 토론 없이 답만 나옵니다)
  - Claude Pro 또는 Max
  - Google 계정 (Gemini CLI는 무료 사용량 있음)
  - ChatGPT Plus 또는 Pro

### 4-2. 프로그램 2개 설치 (그냥 "다음"만 누르면 됩니다)
1. **Python**: https://www.python.org/downloads/ 에서 다운로드 후 설치
   - ⚠️ Windows 설치 첫 화면에서 **"Add python.exe to PATH" 체크박스를 꼭 체크**하세요.
2. **Node.js**: https://nodejs.org/ 에서 **LTS** 버전을 다운로드 후 설치

### 4-3. AI 프로그램 설치
터미널을 엽니다.
- Windows: 시작 버튼 → "PowerShell" 검색 → 실행
- Mac: Spotlight(⌘+스페이스) → "터미널" 실행

아래 세 줄을 **한 줄씩** 복사해서 붙여넣고 Enter를 누르세요. 쓰지 않는 AI는 건너뛰어도 됩니다.

```
npm install -g @anthropic-ai/claude-code
npm install -g @google/gemini-cli
npm install -g @openai/codex
```

> Mac에서 "permission denied"가 뜨면 앞에 `sudo `를 붙이고 PC 비밀번호를 입력하세요.

### 4-4. 각 AI에 로그인 (각각 한 번만)
터미널에서 하나씩 입력합니다. 입력하면 **브라우저가 열리고 평소처럼 로그인**하면 됩니다.

| 입력 | 그다음 할 일 |
|---|---|
| `claude` | 로그인 방법에서 구독 계정을 고르고 로그인 → 끝나면 `/exit` 입력 |
| `gemini` | "Login with Google" 선택 → 로그인 → 끝나면 `/quit` 입력 |
| `codex login` | ChatGPT 계정으로 로그인 |

### 4-5. AI Council 내려받기
1. https://github.com/dream8837z/Claude-Main-Skill 접속
2. 초록색 **Code** 버튼 → **Download ZIP**
3. 압축을 풀고 안에 있는 **`council` 폴더**를 찾아 둡니다. 바탕화면에 두면 편합니다.

> 아직 PR이 병합되지 않았다면, 저장소 화면에서 브랜치를 `claude/inspiring-knuth-noixiw`로 바꾼 뒤 내려받으세요.

## 5. 매번 쓰는 방법

### PC에서 켜기
- **Windows:** `council` 폴더의 **`start-windows.bat`** 더블클릭
- **Mac:** **`start-mac.command`** 더블클릭
  - 처음에 "확인되지 않은 개발자"라고 막히면: 파일을 **우클릭 → 열기 → 열기**

까만 창에 이런 주소가 나옵니다:
```
http://192.168.0.12:8787/?t=Ab3xYz9Q
```

> Windows에서 "방화벽 허용" 창이 뜨면 **개인 네트워크 허용**을 누르세요.

### 휴대폰에서 쓰기
1. 휴대폰이 **PC와 같은 와이파이**에 연결됐는지 확인합니다.
2. 휴대폰 브라우저(사파리나 크롬) 주소창에 위 주소를 **`?t=...`까지 전부** 입력합니다.
3. 질문을 쓰고 **[토론 시작]** 을 누릅니다.
4. 몇 분 기다리면 최종 답이 나옵니다. "토론 전체 과정 보기"를 누르면 AI들이 무슨 이야기를 했는지 볼 수 있습니다.

**꿀팁:** 브라우저 공유 버튼 → **"홈 화면에 추가"** 를 누르면 앱처럼 아이콘이 생깁니다.

> `?t=` 뒤의 글자는 **비밀번호 역할**입니다. 같은 와이파이의 다른 사람이 내 AI를 쓰지 못하게 막아 줍니다. 프로그램을 다시 켤 때마다 바뀝니다.
> 항상 같은 주소를 쓰고 싶다면 `start-windows.bat`(또는 `start-mac.command`)을 메모장으로 열고, `web.py`를 `web.py --token 나만아는긴글자`로 바꿔 저장하세요.

### 끄기
까만 창을 닫거나, 창에서 `Ctrl + C`를 누릅니다.

## 6. 더 잘 쓰는 법

**토론 횟수 고르기 (화면의 "토론 횟수")**
- `0`: 각자 답 → 투표 → 정리. 가장 빠름
- `2`: 기본값. 대부분 이걸로 충분
- `3`: 중요한 문제. 느리고 사용량이 많이 듦

**좋은 질문 쓰는 법**
- 목적, 조건, 원하는 형식을 함께 적으세요.
  - 나쁜 예: "마케팅 문구 써줘"
  - 좋은 예: "30대 직장인 대상 단백질 음료 인스타그램 문구 3개. 각 50자 이내, 이모지 1개씩."

**토론 횟수·참여 AI 바꾸기 (선택)**
- `council.config.json`을 메모장으로 열어 수정합니다.
  - 특정 AI를 빼고 싶으면: 해당 줄에 `"enabled": false`를 넣습니다.
  - 정리를 맡을 AI 바꾸기: `"judge": "gemini"`

## 7. 밖에서(집 와이파이가 아닐 때) 쓰고 싶다면

기본 설정은 **같은 와이파이에서만** 됩니다. 이 방식이 가장 안전합니다. 밖에서도 쓰려면 **Tailscale**(무료, 개인용)을 추천합니다.

1. PC와 휴대폰 모두 https://tailscale.com 앱을 설치하고 **같은 계정**으로 로그인
2. Tailscale 앱에서 PC의 주소(`100.`으로 시작)를 확인
3. 휴대폰에서 `http://100.x.x.x:8787/?t=...`로 접속

> ⚠️ 공유기 "포트포워딩"으로 인터넷에 직접 공개하는 방법은 **권하지 않습니다**. 남이 내 구독을 쓸 위험이 있습니다.

## 8. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 휴대폰에서 주소가 안 열림 | ① 같은 와이파이인지 확인 ② PC의 까만 창이 켜져 있는지 확인 ③ Windows 방화벽에서 Python을 "개인 네트워크" 허용 ④ 회사·카페 와이파이는 기기끼리 연결을 막기도 함 → 휴대폰 핫스팟에 PC를 연결해 보기 |
| "주소가 올바르지 않습니다" | `?t=...`까지 **전부** 입력했는지 확인. 프로그램을 다시 켰다면 새 주소를 사용 |
| 참여 모델이 "(없음)"으로 나옴 | 4-3 설치가 안 된 상태. PC를 재부팅한 뒤 다시 확인 |
| 결과에 `[ERROR gemini ...]` | 해당 AI 로그인이 풀린 것. 4-4를 다시 하기 |
| `'python'은(는) 내부 또는 외부 명령...` | Python 설치 때 PATH 체크를 빠뜨림 → Python을 다시 설치하며 체크 |
| 너무 오래 걸림 | 토론 횟수를 0~1로 줄이기. 한 AI가 10분 넘게 응답이 없으면 자동으로 건너뜀 |

## 9. 꼭 알아 두세요

- **사용량:** AI 3개로 토론을 2번 하면 질문 1개에 AI 호출이 약 13번 일어납니다. 구독 사용 한도가 평소보다 빨리 찹니다.
- **약관:** 공식 프로그램을 내 PC에서 내가 실행하는 방식이지만, 자동으로 반복 사용하는 것에 대한 각 회사 약관은 직접 확인하세요.
- **개인정보:** 질문 내용은 각 AI 회사로 전송됩니다. 민감한 정보는 넣지 마세요.
- **기록:** 모든 토론 기록은 `council/runs/` 폴더에 저장됩니다. 필요 없으면 지워도 됩니다.
- **확인되지 않은 부분:** Gemini와 ChatGPT(Codex) 프로그램은 버전에 따라 명령어가 바뀔 수 있습니다. 결과에 계속 `[ERROR ...]`가 뜨면 그 내용을 복사해 Claude에게 물어보세요.
